# Как получить QR код для Expo

## Способ 1: В терминале (основной)
1. Откройте PowerShell или CMD
2. Перейдите в директорию: `cd "D:\AI Poker Notes\apn-mvp\apps\mobile"`
3. Запустите: `npm start`
4. QR код появится в терминале

## Способ 2: Через веб-интерфейс
1. После запуска `npm start` откройте в браузере: http://localhost:8081
2. В веб-интерфейсе будет отображён QR код
3. Нажмите на кнопку "Show QR code" если он не виден

## Способ 3: Tunnel mode (если устройство в другой сети)
1. Запустите: `npx expo start --tunnel`
2. Expo использует ngrok для создания публичного URL
3. QR код будет работать из любой сети

## Способ 4: Прямое подключение по IP
1. Узнайте IP адрес компьютера в локальной сети
2. На телефоне в Expo Go введите вручную: `exp://ВАШ_IP:8081`

## Установка Expo Go на телефон:
- **Android**: Google Play Store → "Expo Go"
- **iOS**: App Store → "Expo Go"

## Горячие клавиши в терминале Expo:
- `r` - перезагрузить приложение
- `s` - переключить между LAN/localhost/tunnel
- `w` - открыть в браузере
- `a` - запустить на Android эмуляторе
- `i` - запустить на iOS симуляторе
- `q` - остановить сервер
